# Custom Data Toolkit 测试与验收

> 状态：Test Baseline（draft）  
> 上游文档：`requirements.md`、`spec.md`、`api.md`

## 1. 测试分层

### 后端单元测试

- 密码哈希与校验。
- API Key 生成与哈希比对。
- 货币删除前「是否仍有汇率」判断。
- 日期区间参数校验（from ≤ to）。

### 后端集成测试

- MySQL 约束与 Alembic 迁移（含既有表对齐）。
- 登录、退出、CSRF、会话过期。
- 货币 CRUD；有汇率时删除冲突。
- 汇率唯一键冲突。
- API Key 创建后可用、停用后 401。
- 对外 `/public/rates` 单日与区间查询。

### 前端测试

- 登录表单校验与错误提示。
- 货币列表/新建/编辑/删除确认。
- 汇率筛选与分页空态。
- API Key 创建后明文展示与关闭后不可再见。
- 加载、错误、重试。

### Smoke / E2E

- 前后端健康检查。
- 管理员登录进入后台。
- 创建货币 → 创建汇率 → 列表可见。
- 创建 API Key → 用 Key 调用公开查询成功。
- 停用 Key 后公开查询失败。

## 2. 认证验收

- [ ] 无自助注册入口与接口。
- [ ] 预置管理员可登录。
- [ ] 登录错误不泄露用户是否存在。
- [ ] 会话 Cookie HttpOnly。
- [ ] CSRF 失败不能写数据。
- [ ] 退出后管理接口 401。

## 3. 货币与汇率验收

- [ ] 货币增删改查符合 `spec.md`。
- [ ] 有关联汇率时不能删货币。
- [ ] 同货币同日汇率冲突 409。
- [ ] 可维护 `data` 与 `checked`。
- [ ] 列表筛选与分页正确。

## 4. API Key 与对外查询验收

- [ ] 创建响应含一次性明文；列表不含完整明文。
- [ ] 有效 Key 可查单日与区间。
- [ ] 无效/停用 Key 返回 401。
- [ ] 未知 code 返回 404；无数据返回空列表。

## 5. 范围验收

- [ ] 无海关字典页面、路由、表、API。

## 6. 完成定义（切片级）

一个切片完成当且仅当：

1. 对应 Spec/API/DB 已更新（若有行为变化）。
2. 相关自动化测试通过。
3. 手工或 smoke 验证关键路径。
4. `progress.md` 已记录。
