# Proposal: 货币与汇率搜索前缀推荐

## Status

**Proposed（需求已确认，待逐切片实施）**

## Intent

管理员在货币管理的「名称或字母代码」搜索框、汇率管理的「字母代码」搜索框输入内容时，可看到前缀匹配的货币推荐，减少输入错误并加快定位。

## Scope

In Scope:

- 货币管理：按名称或 `code` 前缀推荐
- 汇率管理：按 `code` 前缀推荐
- 匹配忽略大小写
- 完全匹配优先，其次 code 前缀、名称前缀，同组按 code / 名称排序
- 每次最多返回并展示 10 条推荐
- 下拉列表支持鼠标滚轮上下滚动，不提供服务端翻页
- 点击推荐项只填入搜索框，不自动搜索
- 复用同一管理端推荐 API

Out of Scope:

- 模糊/包含/编辑距离搜索
- 自动执行搜索
- 新建/编辑货币的重名提醒（见独立 change）
- 点击汇率数量跳转筛选
- 操作记录、撤销与重做

## Impact and Risks

- 涉及管理端 API、货币 repository/service/router、两个前端页面及测试。
- 不改变既有 `GET /currencies?q=` 的模糊查询语义。
- 输入联想可能产生高频请求；实现时需防抖并限制返回数量。
- 仍使用管理端 Session 鉴权；不影响公开 API。
