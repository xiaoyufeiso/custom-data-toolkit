# Proposal: 货币同名软提醒

## Status

**Deferred（已澄清，暂不实现）**

## Intent

新建或编辑货币时，帮助管理员发现已有相同或前缀相似名称，减少无意重复；业务仍允许保存同名货币。

## Scope

In Scope:

- 输入名称时按名称前缀展示已有货币推荐
- 点击推荐名称后，在输入框下方以浅色小字显示“已存在 n 条同名货币”
- 同名按 trim 后大小写不敏感的精确名称计算
- 保存时如存在同名货币，二次确认后仍可保存
- 编辑时推荐、计数和保存检查排除当前货币自身

Out of Scope:

- 禁止同名或增加名称唯一约束
- 模糊/包含搜索
- 相似 code 提醒
- 未点击推荐时持续显示同名数量
- 操作记录与撤销

## Impact and Risks

- 涉及管理端 API、货币表单和测试；数据库语义不变。
- 提醒是软约束，不能保证没有重复数据。
- 同名计数与保存前确认必须使用同一规范化规则，避免提示不一致。
