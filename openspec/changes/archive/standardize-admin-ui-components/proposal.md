# Proposal: 管理端 UI 组件库化与视觉统一

## Status

**Proposed（货币/汇率完成；API Key 管理页搁置；登录页待实施）**

## Intent

当前管理端业务页虽然部分使用 `tendata-ui`，但表格、分页、表单控件、确认交互和新建汇率货币选择器仍混用原生元素及自定义视觉规则，导致页面风格不一致、重复造轮子和维护成本上升。

本变更以组件库默认主题为视觉基线，优先复用 `tendata-ui` 与 `@tendata-biz-components/biz-table`，先完成页面级“大效果”统一，再处理国际化、可访问性和细节样式等“小效果”。

## Scope

In Scope:

- 货币管理、汇率管理、API Key 管理、登录页
- 三个业务列表改用 `@tendata-biz-components/biz-table`
- 分页改用 `tendata-ui Pagination`
- 新建/编辑表单改用 `tendata-ui Modal` 与组件库表单控件
- 删除确认改用 `Popconfirm` 或组件库等价能力
- 汇率筛选改用 `Select`、`DatePicker`、`Checkbox` 等组件
- 保留新建汇率货币选择器的首字母索引能力，并用 tendata-ui 原语重组
- 采用组件库默认主题，业务样式仅保留布局和领域专属交互所需部分
- 小效果阶段完成范围内用户文案的 `react-intl` 接入和可访问性整改

Out of Scope:

- 后端 API、数据库、迁移、认证和权限语义
- 货币、汇率、API Key 的业务规则变化
- 首页、工作台、示例页面及全站重新设计
- 新增或升级依赖、修改构建配置
- 已暂缓的前缀推荐、同名提醒、汇率数量、操作记录和撤销需求
- 放弃或削减已确认的货币首字母索引功能

## Expected Outcomes

- 核心管理页面不再自建表格、分页和通用按钮样式。
- 同类交互具有一致的加载、空态、分页、表单和确认体验。
- 页面主要视觉由组件库主题控制，显著减少硬编码颜色与状态样式。
- 现有业务行为、API 请求和权限边界保持不变。

## Impact and Risks

- 影响四个页面及相关样式和前端测试，属于大范围 UI 重构。
- BizTable、Modal 与现有状态逻辑的集成可能暴露组件 API 差异，应逐页实施和验收。
- 新建汇率货币选择器有领域专属交互，不能机械替换成普通 Select。
- 改造期间容易误改分页、排序、表单提交或一次性密钥展示行为，必须按页面回归。
