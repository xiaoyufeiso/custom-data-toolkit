# 产品需求

## 产品概述

Custom Data Toolkit 是海关数据处理辅助工具的后台管理系统。MVP 聚焦货币与汇率的管理维护，并向外部系统提供可鉴权的汇率查询 API。海关字典管理仅保留扩展占位，本轮不实现。

## 目标用户

- 管理员：维护货币、汇率与 API Key。
- 外部调用方：通过 API Key 查询汇率的系统/服务。

## 用户故事

### 管理货币
作为管理员，我希望增删改查货币主数据，以便汇率数据有正确的货币映射。
- 验收标准：可完成 CRUD；有关联汇率时不能删除。

### 管理汇率
作为管理员，我希望查看并维护全球汇率及核对状态，以便修正爬虫数据。
- 验收标准：可按货币与日期筛选；可改 `data`/`checked`；同货币同日唯一。

### 对外查询
作为外部系统，我希望用 API Key 按货币 code 与日期条件查询汇率。
- 验收标准：单日与区间查询可用；无效 Key 被拒绝。

### 管理 API Key
作为管理员，我希望创建与停用 API Key。
- 验收标准：明文仅创建时可见；停用立即失效。

## 业务规则

- MUST：管理端写操作需登录会话；对外查询需有效 API Key。
- MUST：复用既有 MySQL `currency`/`rate` 表语义。
- MUST NOT：本轮实现海关字典。
- MUST NOT：开放自助注册。

## 范围界定

### In Scope
- 预置管理员登录
- 货币 CRUD、汇率管理、API Key、对外查询 API
- 文档与 Spec 基线

### Out of Scope
- 海关字典业务
- 爬虫采集
- Casdoor/Casbin
- 公网高可用部署

## 成功指标

- 管理端可完成货币与汇率维护闭环
- 外部系统可用 Key 查询汇率
- Spec 足以驱动 AI Coding 切片
