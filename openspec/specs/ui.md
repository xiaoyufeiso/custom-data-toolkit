# UI 交互

## 设计语言

- 形态：后台管理系统
  - **顶栏**：通栏一整行（产品名仅一处）+ 语言切换；不放业务菜单与用户入口
  - **左侧栏**：业务入口（货币 / 汇率 / 海关数据字典 / 系统管理），由路由 `meta.menu` 派生；**系统管理**（用户管理、操作审计）仅 `admin` 可见；viewer 侧栏无该分组；**左下角**展示当前用户名，点击展开菜单仅「退出登录」
  - **内容区**：面包屑（首页 / 分组 / 当前页）在页面标题上方；当前路由页面
  - 「筛选条件」与「查询列表」标题字号/字重一致
  - 筛选区：筛选项与「查询 / 重置 / 刷新」分区排布，查询为主按钮
  - **即时查询**：下拉框变更后立即查询；文本搜索在选中推荐值、按回车、清空或点「查询」时提交（输入过程不自动查）；指定日期选完即查；日期范围左右都选齐（或清空）后即查
  - 状态字段（核对、同步、来源、详情启停）优先用 Tag
  - 批量 footer 选中数量数字加粗放大强调
  - 列表空状态统一 BizTable `noData`（组件库空态图标 +「暂无…」文案），禁止仅用 `locale.emptyText`
  - 分页：`showSizeChanger` + `pageSizeOptions`；改页大小回第 1 页；刷新/重载清空行选中
  - 查询主按钮文案统一 `common.action.query`（「查询」）
- 登录等 `meta.public` 页：隐藏侧栏，仅保留顶栏
- 组件库：优先 tendata-ui（随 Tendata/公司前端模板）
- 反馈：操作成功/失败 Toast 或等价提示；删除需确认

## 页面流程

1. `/login` → 登录成功 → `/`（或 `/currencies`）
2. 侧栏业务组：货币管理 / 汇率管理 / 海关数据字典 → 对应列表页
3. 侧栏「系统管理」仅 admin（用户管理 + 操作审计）；viewer 不可见；左下角用户菜单仅退出
4. 列表页 → 新建/编辑抽屉或弹窗 → 提交回列表（**仅 admin**；viewer 只读）
5. （搁置）API Key 管理前端：创建成功后一次性展示明文；当前无路由/页面

## 核心页面交互规则

### 登录页
- 用户名、密码；无注册入口
- 错误信息不区分用户是否存在（含停用账号）
- 登录成功后缓存当前用户角色供侧栏同步渲染；退出时清除；角色未知时不展示 `roles` 限制菜单（避免 viewer 闪出用户管理）
- 多标签 / 同浏览器换账号：窗口聚焦、页可见、约 10s 轮询与 `BroadcastChannel` 重验 `/auth/me`；身份变化 Toast「账号已切换」并刷新侧栏；若当前页仅 admin 可进则退回业务首页
- Session 失效（含停用清会话）：任意管理端请求 `401 Auth.Unauthorized` 或重验失败 → Toast「登录已失效」并踢回登录（不向用户暴露「已停用」）
- 登录页视觉/组件库对齐仍见活跃 change `standardize-admin-ui-components`

### 用户管理（仅 admin）
- 路由 `/admin-users`；侧栏「系统管理」分组；`roles: ['admin']` + `RequireAdmin`；viewer 侧栏不可见，直链重定向业务首页并 Toast
- 分页列表；可选用户名 `q`、角色、启停筛选（筛选即查）
- 列：选择框、用户名、角色（纯文案）、启停 Tag；列表不展示时间；详情含创建/更新时间（`YYYY-MM-DD HH:mm:ss`）
- 底部批量停用 / 批量启用（二次确认；不可选自己）
- 新建：用户名 + 初始密码 + 角色；详情 Drawer 内改角色/启停；重置密码 Modal（二次确认）
- 对齐 QueryListCard / 列表规范

### 操作审计（仅 admin）
- 路由 `/audit-logs`；侧栏「系统管理」分组；`roles: ['admin']` + `RequireAdmin`；viewer 侧栏不可见，直链重定向并 Toast
- 列：时间（点击表头三态排序：默认倒序 / 正序 / 倒序）、操作者、操作；**无资源列、无独立操作列、无勾选批量**
- 点击「操作」文案打开只读详情 Drawer（`detailGrid` 对齐其它业务页：资源类型、对象、数量、对象 ID）
- 后端仍存 `summary`（非敏感上下文），详情按字段展示，不 dump JSON
- 操作与资源类型筛选项联动：选操作锁定资源类型；选资源类型过滤操作列表

### 货币列表
- 分页；支持按名称/code 搜索（`q`）
- 搜索框支持名称/code 前缀推荐（最多 10 条）；选中推荐、回车、清空或点「查询」即提交
- 当前页行选择 + 页面顶部批量删除（操作列无删除）；删除有关联汇率时展示服务端错误
- 选择在翻页、改页大小、筛选变化或刷新后清除

### 汇率列表
- 筛选区标题统一「筛选条件」；主按钮文案「查询」（非「筛选/搜索」）；列表无 ID 列；排序列（如日期）与其它列视觉完全一致（Table token 抹平 sort 底色）
- 查询列表标题行承载新建等行级操作；选中后批量操作为 Layout Content 内底部 footer（主区滚动时仍可见，不超出 content）
- 详情 Drawer 只读；编辑/处理点击后打开与新建同款 Modal；字典「停用」文案统一为「删除」（后端仍为 disable 软删）
- code 筛选支持 code 前缀推荐；选中推荐、回车、清空或点「查询」即提交；日期模式/核对状态下拉变更即查；指定日期选完即查；日期范围两端选齐或清空即查
- 支持新建/编辑 `data` 与 `checked`
- 批量核对经确认后调用 `POST /rates/batch-check`；已核对幂等
- **新建汇率**货币选择：自定义下拉；选项文案 `code (name)`（无 code 仅名称）；按 `code` 首字母分组；无 code 归 `#`；右侧仅展示有数据的字母索引

### 海关数据字典（第一版）
- **标准字典**：统一列表 + 字典类型筛选；关键词 `q` 模糊匹配原始值或标准值（OR）；原始值、标准值、启停、同步状态；原始值不可改；启停代替删除；单条/重放增量同步（无整表覆盖全量）；列表标题行仅「新建映射」；新建弹窗分「单条新建 / 批量导入」：批量页小字链接触发下载模板、「选择文件」后本地可滑动预览与条数统计，点「确认导入」后进入结果页（统计/失败明细 +「完成」关闭），不再留在预览页；前端暂不提供导出入口
- **缺失字典**：读 Redis ZSET；未选类型时聚合全部启用类型；原始值模糊筛选；处理（正式同步成功后删除 missing）；可导出；无导入
- **字典类型**：关键词模糊匹配编码或名称
- 三页文本搜索对齐货币页：`AutoComplete` 宽 160、debounce 推荐；选中推荐、回车、清空或点「查询」即提交；字典类型等下拉变更即查；标准字典推荐按原始值/标准值模糊包含（与列表 `q` 一致），命中标准值时选项以标准值优先展示并可填入
- 不做：处理历史（见 `openspec/specs/customs-dict/spec.md` Deferred）；管理端操作审计见 `openspec/specs/audit/spec.md`

### API Key 列表（前端搁置）
- 后端管理 API 仍可用；前端路由/页面/服务已移除（2026-07-31）
- 恢复时需重建 UI，并继续 deferred：筛选、批量删除、BizTable 对齐

## 通用交互规范

- 表单提交后 MUST 显示成功/失败反馈
- 删除与批量破坏性操作 MUST 二次确认
- 列表页 SHOULD 支持分页
- 加载中 MUST 显示 loading
- 未登录访问管理页 MUST 跳转登录
- 已登录但角色不足（如 viewer 访问用户管理）MUST 拒绝并离开该页
- 同浏览器其它标签切换账号后，本页 MUST 尽快同步身份或离开无权限页；停用导致 Session 失效后 MUST 尽快踢回登录
- viewer 业务页 MUST 隐藏写操作与导入；MUST 保留查询与字典导出
- 服务端业务错误 MUST 展示用户可读文案，不追加错误码

## 响应式要求

- MVP 以桌面后台为主；不强制移动端完整适配

## 可访问性

- SHOULD：关键按钮具备可辨识文本；表单 label 完整
