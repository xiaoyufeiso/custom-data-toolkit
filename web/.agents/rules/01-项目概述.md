# 01 项目概述

## 项目目标

本项目是一个React前端项目模版，核心目标有两类：

- **业务可用**：适合复杂查询条件、表格、图表、详情页、报告页等中后台业务场景
- **AI 友好**：通过稳定结构和明确边界，让 AI 能持续生成可维护代码

## 当前统一技术基线

| 类别 | 技术选型 |
|------|----------|
| 框架 | `React 18` |
| 语言 | `TypeScript 5` |
| 构建 | `Vite` |
| UI | `tendata-ui`（内部包，底层基于 Ant Design 5） |
| 组件体系 | `tendata-ui` |
| 图标库 | `@tendata-ui/icon` |
| 工具库 | `tendata-utils` |
| 状态管理 | `Zustand + SWR` |
| 样式 | `Less + CSS Modules` |
| 国际化 | `react-intl 10` |
| 路由 | `react-router-dom 6` |
| 请求库 | `axios` |


## 基本原则

- 优先可维护性，不追求炫技实现
- 优先业务范式统一，不接受每个页面一套写法
- 优先类型清晰、边界清晰，不把逻辑堆进页面组件
- 优先增量演进，避免一次性大重构

## 约束案例

### ✅ 正确：遵循统一技术基线

```tsx
// 使用项目统一的技术栈
import { useState } from 'react';
import { Button } from 'tendata-ui';
import styles from './index.module.less';
```

### ❌ 错误：引入基线外的技术方案

```tsx
// 不允许：引入 styled-components 替代 Less + CSS Modules
import styled from 'styled-components';

// 不允许：引入 Redux 替代 Zustand
import { useSelector } from 'react-redux';

// 不允许：引入 Vue 或其他框架组件
import { ref } from 'vue';
```

### ✅ 正确：增量演进

```text
需求：旧页面使用了 Antd 3 的 Form
做法：新页面统一使用 Antd 5 Form，旧页面在需求迭代时逐步迁移
```

### ❌ 错误：一次性大重构

```text
做法：一次性把所有旧页面全部重写为新架构
风险：影响面过大、测试成本不可控、容易引入回归缺陷
```
