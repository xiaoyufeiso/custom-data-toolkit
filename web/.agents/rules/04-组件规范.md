# 04 组件规范

## 组件目录结构

```text
views/tradeSearch/
  index.tsx                  # 页面入口，只做组装
  index.module.less          # 页面样式
  services/                  # 页面私有接口
    index.ts
  components/                # 页面私有业务组件
    searchForm.tsx
    tradeTable/              # 目录结构与tradeSearch一致
  hooks/                     # 页面业务 hooks
    useTradeSearch.ts
  types/                     # 类型定义
    index.ts
  utils/                     # 业务工具函数
    index.ts
  constants/                 # 常量定义
    index.ts
```


## 约束案例

### ✅ 正确：每个组件的文件都收敛到一个文件夹中

```text
components/
   tradeTable/
     index.tsx
     index.module.less
     services/                  # 页面私有接口
        index.ts
     components/                # 页面私有业务组件
        tradeTable/              # 目录结构与tradeSearch一致
     hooks/                     # 页面业务 hooks
        useTradeSearch.ts
     types/                     # 类型定义
        index.ts
     utils/                     # 业务工具函数
        index.ts
     constants/                 # 常量定义
        index.ts

```

### ❌ 错误：组件下的文件都平铺在components文件夹下

```text
components/
   tradeTable.tsx
   tradeTable.module.less
   tradeTable.services.index.ts
   tradeTable.hooks.index.ts
   tradeTable.types.index.ts
   tradeTable.utils.index.ts
   tradeTable.constants.index.ts
```

### ✅ 正确：表格列定义单独维护

```tsx
// columns.tsx
export const tradeColumns: ColumnsType<TradeItemViewModel> = [
  { title: '国家', dataIndex: 'countryName', width: 120 },
  { title: '金额', dataIndex: 'amount', render: (val) => formatMoney(val) },
  { title: '日期', dataIndex: 'date', render: (val) => formatDate(val) },
];
```

### ❌ 错误：列定义内联在页面 JSX 中

```tsx
// 页面组件中直接内联列定义
<BizTable
  columns={[
    { title: '国家', dataIndex: 'countryName', width: 120 },
    { title: '金额', dataIndex: 'amount', render: (val: number) => `$${val.toLocaleString()}` },
    // ... 更多列
  ]}
  dataSource={data}
/>
```

### ✅ 正确：优先复用组件库

```tsx
// 优先使用 tendata-ui 的组件
import { Button } from 'tendata-ui';
import BizTable from '@tendata-biz-components/biz-table';

// 而不是自己封装一个按钮或表格
```

### ❌ 错误：重复造轮子

```tsx
// tendata-ui 已有 TdButton，不应自行封装
const MyButton: React.FC<{ type: string; children: React.ReactNode }> = ({ type, children }) => (
  <button className={`btn btn-${type}`}>{children}</button>
);
```
