# 06 路由规范

## 路由原则
- 路由命名使用`kebab-case`,例如：`/home/trade-list`
- 路由按业务域组织
- 页面默认懒加载
- 路由元信息统一管理

## 页面接入要求

- 页面放在 `pages`
- 页面核心实现放在 `views`
- 需要权限控制的页面必须接入统一鉴权能力

## 查询页要求

- 支持 URL 同步关键筛选条件
- 支持从 URL 恢复页面状态
- 页面返回后尽量保留用户上下文

## 约束案例

### ✅ 正确：路由懒加载 + 元信息管理

```tsx
// app/routes.tsx
import { lazy } from 'react';

const TradeSearch = lazy(() => import('@/pages/tradeSearch'));
const TradeDetail = lazy(() => import('@/pages/tradeDetail'));

export const routes = [
  {
    path: '/trade-search',
    element: <TradeSearch />,
    meta: { title: '贸易搜索', authKey: 'trade:search' },
  },
  {
    path: '/trade-detail/:id',
    element: <TradeDetail />,
    meta: { title: '贸易详情', authKey: 'trade:detail' },
  },
];
```

### ❌ 错误：页面不做懒加载、路由无元信息

```tsx
// 直接全量导入，无 meta 信息
import TradeSearch from '@/pages/TradeSearch';
import TradeDetail from '@/pages/TradeDetail';

export const routes = [
  { path: '/trade/search', element: <TradeSearch /> },
  { path: '/trade/detail/:id', element: <TradeDetail /> },
];
```

### ✅ 正确：URL 同步查询参数

```tsx
// views/tradeSearch/hooks/useTradeSearch.ts
import { useSearchParams } from 'react-router-dom';

export function useTradeSearch() {
  const [searchParams, setSearchParams] = useSearchParams();

  const keyword = searchParams.get('keyword') ?? '';
  const country = searchParams.get('country') ?? '';

  const onSearch = (values: TradeSearchFormValues) => {
    setSearchParams({ keyword: values.keyword, country: values.country });
  };

  return { keyword, country, onSearch };
}
```

### ❌ 错误：查询参数硬编码，不与 URL 同步

```tsx
// 页面跳转后查询参数丢失，无法通过 URL 恢复页面状态
const [keyword, setKeyword] = useState('');
const [country, setCountry] = useState('');
```
