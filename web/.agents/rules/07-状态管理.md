# 07 状态管理

## 状态分层原则

| 工具 | 职责 | 适用场景 |
|------|------|----------|
| `Zustand` | 前端本地状态 | 主题、语言、布局、用户偏好、表格列配置、跨页面临时上下文 |
| `SWR` | 服务端数据状态 | 列表数据、详情数据、统计指标、图表数据、字典数据 |

## 强制约束

- 不把远程数据长期塞入 Zustand
- 不把 UI 状态和远程状态混写在一个 store
- 所有复杂查询页都要有清晰的数据流入口

## 推荐数据流

```text
Page → Feature Hook → SWR Hook → API
```

## 约束案例

### ✅ 正确：Zustand 管理本地 UI 状态

```ts
// store/useAppStore.ts
import { create } from 'zustand';

interface AppState {
  locale: string;
  theme: 'light' | 'dark';
  setLocale: (locale: string) => void;
  setTheme: (theme: 'light' | 'dark') => void;
}

export const useAppStore = create<AppState>((set) => ({
  locale: 'zh_CN',
  theme: 'light',
  setLocale: (locale) => set({ locale }),
  setTheme: (theme) => set({ theme }),
}));
```

### ❌ 错误：把远程数据塞进 Zustand

```ts
// 不应该把列表数据、接口返回放进 Zustand 长期管理
export const useTradeStore = create((set) => ({
  tradeList: [],         // ❌ 远程数据不应放在 Zustand
  loading: false,
  fetchTrades: async () => {
    set({ loading: true });
    const res = await axios.get('/api/trade');
    set({ tradeList: res.data, loading: false }); // ❌ 应使用 SWR
  },
}));
```

### ✅ 正确：SWR 管理服务端数据

```ts
// views/tradeSearch/hooks/useTradeList.ts
import useSWR from 'swr';
import { fetchTradeList } from '../services';

export function useTradeList(params: TradeSearchParams) {
  const { data, error, isLoading, mutate } = useSWR(
    ['trade-list', params],
    () => fetchTradeList(params),
  );

  return { data: data?.list ?? [], total: data?.total ?? 0, isLoading, error, refresh: mutate };
}
```

### ❌ 错误：UI 状态和远程状态混写在一个 store

```ts
// 主题、语言等 UI 状态与贸易数据混在同一个 store 中
export const useGlobalStore = create((set) => ({
  theme: 'light',
  locale: 'zh_CN',
  tradeList: [],         // ❌ 远程数据不应和 UI 状态混在一起
  setTheme: (theme: string) => set({ theme }),
  fetchTrades: async () => {
    const res = await axios.get('/api/trade');
    set({ tradeList: res.data });
  },
}));
```
