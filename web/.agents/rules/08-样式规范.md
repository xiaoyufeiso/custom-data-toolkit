# 08 样式规范

## 统一方案

- 样式统一采用 `Less + CSS Modules`

## 基本规则

- 页面样式优先使用 `index.module.less`
- 组件根元素样式名称应与组件名称一致，使用`camelCase`, 例如：
  - 组件名称为`TradeCard`，则根元素样式名称为`tradeCard`
- 组件样式与组件同目录维护
- 尽量避免全局样式污染
- 尽量避免直接覆盖第三方组件深层 class

## 设计一致性

- 优先复用主题 token 和已有间距、颜色、圆角规范
- 不为单页方便引入全新视觉规则
- 图标、色值、阴影尽量从统一设计资产中取值

## 禁止项

- 禁止新增 CSS-in-JS 作为主方案
- 禁止组件样式与页面样式互相污染
- 禁止大量内联 style 代替样式文件

## 约束案例

### ✅ 正确：使用 CSS Modules 局部样式

```tsx
// components/TradeCard/index.tsx
import styles from './index.module.less';

const TradeCard: React.FC = () => (
  <div className={styles.tradeCard}>
    <h3 className={styles.title}>贸易数据</h3>
  </div>
);
```

```less
// components/TradeCard/index.module.less
.tradeCard {
  padding: 16px;
  border-radius: @border-radius-base;
  background: @component-background;
}

.title {
  font-size: 16px;
  color: @text-color;
}
```

### ❌ 错误：使用 CSS-in-JS

```tsx
// 不允许引入 styled-components / emotion 等 CSS-in-JS 方案
import styled from 'styled-components';
const Card = styled.div`padding: 16px;`;
```

### ❌ 错误：大量内联 style

```tsx
// 不允许用内联 style 代替样式文件
<div style={{ padding: 16, borderRadius: 8, background: '#fff', boxShadow: '0 2px 8px rgba(0,0,0,0.1)' }}>
  <h3 style={{ fontSize: 16, color: '#333' }}>贸易数据</h3>
</div>
```

### ✅ 正确：复用主题 token

```less
// ✅ 使用主题变量，保持设计一致性
.container {
  padding: @padding-md;
  color: @text-color;
  background: @component-background;
  border-radius: @border-radius-base;
}
```

### ❌ 错误：硬编码色值和间距

```less
// ❌ 直接写死数值，后续主题切换无法统一变更
.container {
  padding: 16px;
  color: #333;
  background: #fff;
  border-radius: 4px;
}
```

### ❌ 错误：覆盖第三方组件深层 class

```less
// ❌ 直接覆盖 Antd 内部 class，版本升级后可能失效
:global {
  .ant-table-thead > tr > th {
    background: #f5f5f5 !important;
  }
}
```
