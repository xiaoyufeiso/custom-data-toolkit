# 项目级 Rules

这套 Rules 用于统一团队成员与 AI Coding 的协作边界，优先服务以下目标：

- 统一技术基线：`React 18 + TypeScript 5 + Vite + tendata-ui`
- 统一 UI 基线：`tendata-ui`
- 统一状态分层：`Zustand + SWR`
- 统一样式方案：`Less + CSS Modules`
- 统一国际化方案：`react-intl 10`
- 统一路由方案：`react-router-dom 6`
- 统一工程结构、命名方式、代码职责和交付标准

## 使用原则

- 开发新功能前，先看 `01-项目概述.md` 和 `03-项目结构.md`
- 写页面和组件前，优先看 `04-组件规范.md`、`08-样式规范.md`
- 写接口和数据逻辑前，优先看 `05-API规范.md`、`07-状态管理.md`
- 涉及路由、权限、页面接入时，看 `06-路由规范.md`
- 提交前，至少自查 `02-编码规范.md`（含通用约束）
- 引入新依赖或组件库前，看 `10-依赖与导入规范.md`
- 写测试时，参考 `09-测试规范.md`
